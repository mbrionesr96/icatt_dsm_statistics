read_csv() allows to import the dataframe as a tibble. A tibble is a modern way to store tabular data in R, the Key differences from base data.frames:

  • Printing: only first 10 rows and columns that fit; shows column types
  • No partial matching: column names must match exactly
  • Subsetting: always returns a tibble (not a vector)

First plot

ggplot(), creates an empty plot we only specify the data that we will be owrking on (optional). We then have various layers added to modify it. For example, the geom_point() function adds a layer representing the scatterplot of hwy vs displ. To set how the variables in the dataset are mapped to the plot we use the aes function contained inside geom_plot.

Here we plot teh relationship between the highway miles per gallon or efficiency (hwy) and engine displacement, in litres or size of engine (displ)

ggplot(data = mpg) + #creates the base plot and the dataset
  geom_point(mapping = aes(x = displ, y = hwy)) #specify the type and variables

Aesthetics

geom_point() is part of a family of functions that we will call GEOM_FUNCTION they vary on type and accept various aesthetics to customize our layer like colour, size and shape.

ggplot(data = mpg) +
  geom_point(mapping = aes(x = displ, y = hwy, color = class)) 
# we could also customise the color of all points by doing it outside the aes function

# ggplot(data = mpg) +
#   geom_point(mapping = aes(x = displ, y = hwy), col = "blue")

We can also associate the class variable with different characteristics of a point, such as its size and shape.

For example, we can define the shape and size of the points by the type of traction in the car (f = front-wheel drive, r = rear wheel drive, 4 = 4 wheel drive)

ggplot(data = mpg) +
  geom_point(mapping = aes(x = displ, y = hwy, size = drv, shape = drv))
Warning: Using size for a discrete variable is not advised.

All possible GEOM_FUNCTIONS allow for aesthetic option, but not all can work with the same aesthetics.For example geom_bar() does not allow for shape option.

ggplot(data = mpg) +
  geom_smooth(mapping = aes(x = displ, y = hwy))
`geom_smooth()` using method = 'loess' and formula = 'y ~ x'

In the graph geom_smooth() is employed to create a sort of trend line. We can modify the linetype and colors as we saw, this will give us a better picture of the trends for the different values of drv.

ggplot(data = mpg) +

Correlation matrixes

A correlation matrix is a table displaying correlation coefficients between multiple variables, measuring the strength and direction of linear relationships. On the other hand, a heat maps is the visual, color-coded representation of a numerical correlation matrix. It displays correlation coefficients between variables using colors to indicate the strength and direction (positive/negative) of relationships, allowing for rapid identification of patterns.

The ggcorrplot package provides functions for creating correlation matrix heatmaps

a Large Language Model (LLM) is a type of artificial intelligence trained on massive text datasets, able to understand and generate language. An LLM learns statistical patterns, not facts or reasoning and this its outputs are probabilistic, not deterministic.

A LLM is not infalable, the are prompt to hallucinations and mistakes, as such there’s a lot of risk associated with truting them for example the decision of a model to make a study as the LLM can do mistaken assumptions that a good data scientist would be able to prevent.

Moreover LLMs are known as terrible at analyzing data: They cannot do simple arithmetic reliably nor even count rows reliably. Having LLMs write/run code that analyzes data is a disaster.
